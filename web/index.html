moofetch .anim converter

Turn an animated GIF / WebP (or a set of image frames) into a moofetch animation. Use it with moofetch --logo-type animation --logo my.anim. Format documentation: examples/README.md.

Animated GIF decoding uses the browser's ImageDecoder API (Chrome, Edge, Safari and recent Firefox). If it is unavailable, drop individual PNG/JPG frames instead — each file becomes one frame, sorted by file name. Everything runs locally; no data leaves your machine.
